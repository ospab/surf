# surf

Браузер на PyQt6. Проект по модулю PyQt в Яндекс Лицее.

Страницы показывает Chromium через `QtWebEngine`. Вкладки, история, закладки, загрузки, режим чтения, блокировка трекеров и остальное написаны поверх него.

## Что умеет

- Вкладки: открыть (Ctrl+T), закрыть (Ctrl+W), дублировать, перетащить, вытащить в отдельное окно. Звук вкладки можно выключить.
- Вкладки с прошлого раза открываются при запуске. Вкладки, которые долго не открывали, засыпают и не занимают память.
- Новая вкладка: поиск и плитки сайтов. Если своих плиток нет, показываются сайты, на которые заходили чаще всего.
- Журнал (Ctrl+H): история с поиском и фильтром по датам, закладки, статистика по сайтам, выгрузка в CSV.
- Загрузки (Ctrl+J), сохранение страницы в PDF (Ctrl+S), снимок страницы (Ctrl+Shift+S), исходный код (Ctrl+U), поиск по странице (Ctrl+F).
- Режим чтения (Ctrl+Alt+R): статья без рекламы и меню, размер шрифта меняется.
- Масштаб (Ctrl+колесо) запоминается для каждого сайта.
- Блокировка рекламных и аналитических трекеров, заголовок Do Not Track.
- Приватное окно (Ctrl+Shift+P): после закрытия ничего не остаётся.
- Сайт может попросить камеру, микрофон, экран или геолокацию. Браузер спросит, а для камеры и микрофона можно выбрать конкретное устройство.
- Тёмная и светлая тема, свой цвет акцента, тёмная тема для сайтов, русский и английский язык.
- Служебные страницы: `surf://welcome`, `surf://history`, `surf://bookmarks`, `surf://downloads`, `surf://protection`, `surf://settings`, `surf://help`, `surf://about`, `surf://pages`.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Сборка exe

```bash
python build.py
```

Готовый браузер появится в `dist/surf/surf.exe`.

## Проверка стиля

```bash
python -m ruff check .
```

Правила лежат в `ruff.toml`.

## Что где лежит

- `main.py`: главное окно, меню, горячие клавиши, загрузки, масштаб, усыпление вкладок.
- `database.py`: всё, что связано с SQLite (`surf.db`), и выгрузка в CSV.
- `i18n.py`: тексты интерфейса на русском и английском.
- `constants.py`: общие константы.
- `ui/`: формы из Qt Designer. `settings.ui` загружается через `uic.loadUi`, `history.ui` собран `pyuic6` в `ui_history.py`.
- `widgets/`: окна и виджеты. Вкладка (`browser_tab.py`), панель вкладок, настройки, журнал, загрузки, режим чтения, сертификат, окно трекеров, запросы разрешений.
- `utils/`: части без своих окон. Блокировка трекеров, страницы `surf://`, значки сайтов, список устройств.
- `styles/`: темы QSS.
- `resources/`: иконки, значок приложения и скрипты, которые встраиваются в страницы.

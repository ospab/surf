# surf — Веб-браузер на PyQt6

**surf** — легковесный, быстрый и функциональный веб-браузер со строгим скруглённым интерфейсом (тёмная и светлая темы surf), встроенным режимом чтения статей (Reader Mode), управлением вкладками с прокруткой и локальной базой данных на SQLite3.

Разработан в рамках проекта по модулю PyQt.

---

## Возможности

- **Многовкладочный интерфейс:**
  - Создание (`Ctrl+T`), закрытие (`Ctrl+W`), дублирование, закрытие других вкладок.
  - Экспресс-панель (Speed Dial) с быстрым переходом к популярным сайтам и поисковой строкой.
  - Полноценный Chromium-движок на базе `QWebEngineView`.
- **Режим комфортного чтения (Reader Mode):**
  - Очистка веб-страницы от баннеров, боковых меню и рекламы.
  - Отображение текста статьи в типографике для чтения на базе `QTextBrowser`.
  - Изменение размера шрифта, переход по внутренним ссылкам.
- **Журнал истории и закладок:**
  - База данных SQLite с таблицами `history`, `bookmarks`, `downloads`, `settings`.
  - Поиск по истории и закладкам в реальном времени.
  - Фильтрация истории по датам (за сегодня, вчера, неделю, всё время).
  - Статистика: аналитика и топ часто посещаемых доменов.
  - Экспорт и импорт закладок и истории в формате **CSV**.
- **Инструменты и диалоги:**
  - Поиск по тексту страницы (`Ctrl+F`) с навигацией вперёд/назад.
  - Снимок экрана веб-страницы (`Ctrl+Shift+S`) с сохранением в PNG/JPEG.
  - Сохранение страницы в PDF (`Ctrl+S`).
  - Просмотр исходного HTML-кода страницы (`Ctrl+U`).
  - Менеджер загрузок с отслеживанием статусов и открытием папки с файлом.
  - Настройки: домашняя страница, поисковая система (Яндекс / Google / DuckDuckGo), папка загрузок, выбор акцентного цвета через `QColorDialog`.

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск браузера
```bash
python main.py
```

### 3. Сборка в независимый .exe (PyInstaller)
```bash
python build.py
```
После сборки готовое приложение будет доступно в папке `dist/surf/surf.exe`.

## Архитектура и структура файлов

- `main.py` — главное окно браузера (`QMainWindow`), меню, тулбар, обработка вкладок (`QTabWidget`), горячих клавиш и загрузок.
- `database.py` — работа с базой данных SQLite3 (`surf.db`), выполнение CRUD-операций, аналитика и экспорт/импорт в CSV.
- `ui/` — формы графического интерфейса:
  - `settings.ui` — загружается динамически через `uic.loadUi` (**способ 1**).
  - `history.ui` — компилируется через `pyuic6` в `ui_history.py` (**способ 2**).
- `widgets/` — специализированные компоненты интерфейса:
  - `browser_tab.py` — вкладка браузера на основе `QStackedWidget` (WebEngine + SpeedDial + ReaderView).
  - `reader_view.py` — режим чтения и просмотр исходного кода на `QTextBrowser`.
  - `history_dialog.py` — менеджер истории, закладок и статистики (`QTableWidget`).
  - `settings_dialog.py` — окно настроек браузера.
  - `download_manager.py` — менеджер загрузок (`QTableWidget`).
- `styles/` — таблицы стилей QSS:
  - `dark.qss` — строгая тёмная тема surf.
  - `light.qss` — строгая светлая тема surf.
